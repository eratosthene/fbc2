Connect eBay

eBay's picture upload and the order earnings Ship This reads only accept OAuth sign-ins, not the token fbc uses for everything else, so fbc needs your permission once. It keeps the token eBay gives it (good for about 18 months) and renews its access from that. If you connected before Ship This existed, connect again so fbc can read order earnings too.
